# Conteudo desta entrega

Este ZIP e uma reconstrução nova da base de projeto para o Codex porque o ZIP antigo nao estava mais recuperavel para download. Mantem objetivo, estrutura de instrucao e nucleo executavel do kickoff, mas nao se afirma byte a byte igual ao arquivo anterior.

## Conteudo verificavel

- Python 3.11+ e sem dependencias de runtime.
- Comandos `demo`, `analyze`, `export`.
- Eventos sinteticos: 6 passos x 6 repeticoes = 36 eventos.
- Banco SQLite e analise de sequencias.
- Testes unitarios (rodar na maquina).
- CI para Windows e Ubuntu.
- Instrucao de trabalho autonomo para o Codex.

## Nao incluido

- Instalador e captura real Windows.
- Integracao DeskMate ou codigo de terceiros.
- Servidor central, prints reais ou sistema completo.
